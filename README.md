# ひかりのしくみ — Energy_3D1024

懐中電灯を分解し、電気回路と回路図の対応を理解するための日本語教材です。問題・クイズ・採点は含みません。

## 使い方

1. 「分解してみる」でレンズ、反射板、後ろのふた、本体、乾電池、LED基板、スイッチが順に離れます。一時停止、スライダー、組み立て直しができます。
2. 「回路図とくらべる」で電気部品を取り出した回路と回路図を並べます。
3. 部品または記号を選ぶと、対応する場所が同時に強調されます。スイッチを切り替えると、実物側と回路図の開閉・LEDの点灯が連動します。

ドラッグで回転、ピンチまたはホイールで拡大縮小。3D表示にフォーカスして矢印キーで回転、`+` / `-` で拡大縮小、`0` で視点を戻せます。

## ローカルで開く

```sh
npm start
```

`http://127.0.0.1:4173` を開きます。Python 3が必要です。ビルド・npmインストールは不要です。ES modulesを使うため、HTMLの直接ダブルクリックではなくHTTPサーバーで開きます。

```sh
npm test
```

## 教材上のモデル

- 特定製品の設計図ではなく、構造と対応を見やすくした学習用の懐中電灯です。
- 電源は乾電池2本。LED基板上の抵抗も、対応する回路図に描いています。定量的な電流・明るさの計算は行いません。
- 分解した状態では点灯しません。「回路図とくらべる」では部品の位置を変え、導線で再び接続しています。
- 回路図は配置や形ではなく、部品間の電気的な接続を表します。
- 補足資料： [Adafruit — All About LEDs](https://learn.adafruit.com/all-about-leds/overview)

## 構成

`dist/` がそのまま配信できる静的サイトです。Three.js r170 と OrbitControls は `dist/vendor/` に同梱（MIT、ライセンスも同梱）。CDN、外部フォント、分析、アカウント、保存用サーバーは使いません。3DにはWebGLが必要です。
