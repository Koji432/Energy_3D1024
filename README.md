# 電気回路

公開URL: https://koji432.github.io/Energy_3D1024/

懐中電灯・扇風機・黒板消しクリーナー・自動掃除機・ゲームコントローラー・ドローン・ロードスターを、アイコンで切り替えて表示します。

- **分解／組み立てアイコン**: 分解アニメーションと組み立てアニメーションを切り替え。
- **製品の電源**: 組み立てたモデルの電源ボタンやスイッチを押すと動作し、再度押すと停止。懐中電灯は点灯、扇風機は羽根、黒板消しクリーナーはブラシ、自動掃除機は走行、コントローラーは振動、ドローンはプロペラ回転。
- **回路／製品アイコン**: 部品の回路と回路図の表示、および製品モデルの表示を切り替えます。
- 部品または記号を選択すると、両方の対応する箇所を強調表示。
- 回路図のスイッチ記号、または3D回路のスイッチを直接押すと、LEDの点灯／モーターの回転が連動します。キーボードのEnter・Spaceでも操作できます。
- **ロードスター**: 2026年公開の車体とRocket構成の機構を参照した模式モデル。車体の電源操作で翼・ファンが動き、圧縮ガスによる短い浮上と着地を表示します。分解で電源・走行モーター・吸引ファン・翼の駆動部・電動バルブ・ガスタンク・ノズルを取り出せます。回路・機構図では電気配線とガス配管を分けています。[設計と参照資料](docs/roadster.md)
- ロードスターの**詳しく**から、走行・床下の吸引・可動翼・ガス噴射の拡大図を開けます。部品を選ぶと対応する機構へ切り替わり、回路図のスイッチに連動して歯車・ロッド・空気・ガスの動きを表示します。

## ローカルで開く

```sh
npm start
```

http://127.0.0.1:4173/ を開きます。Python 3が必要です。ビルドやnpm installは不要です。

```sh
npm test
```

## GitHub Pages

mainへのpushで `.github/workflows/pages.yml` が `npm run build` を実行し、生成した `site/` を公開します。CSS・JavaScript全体を内容のハッシュ付きURLに置き、端末に古いファイルが残っていても、新しいHTMLからは同じ更新のファイルを読み込みます。GitHubログイン不要で開けます。

すでに開いている端末で以前のHTMLが残る場合は、公開URLの末尾に `?v=` と `site/version.json` のバージョン値を付けて開けます。ローカル開発は従来どおり `npm start` だけで動きます。

## ファイル

- `dist/app.js`: 表示・操作・アニメーション
- `dist/models/`: 7種類の3Dモデル
- `dist/circuits.js`: 部品の回路と回路図
- `dist/model.js`: 状態遷移
- `dist/icons.js`: 製品選択・分解・回路／製品切り替えのSVGアイコン
- `dist/vendor/`: Three.js r170とOrbitControls（MITライセンス同梱）

回路図は電源・スイッチ・負荷の接続を簡略化した表示です。自動掃除機・ドローン・コントローラーの制御回路は制御基板のブロックで表しています。コントローラーの負荷は2基の振動モーターです。物理量の計算は行いません。

マウス・タッチで3Dモデルを回転／拡大できます。3D領域にフォーカスして矢印キーで回転、`+` / `-` で拡大縮小、`0` で視点を戻せます。
