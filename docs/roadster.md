# ロードスターのモデル設計

参照時点: 2026年10月29日。

2026年公開のテスラ・ロードスターの外観と、Rocket構成の機構を参照しています。テスラ公式ページは、可動空力部品、床下の吸引システム、電動アクチュエータを備えたコールドガス・スラスターを説明しています。Rocket構成は1人乗りで、車両周囲のスラスターによる前方・上方の加速と回転を扱う構成です。[テスラ公式](https://www.tesla.com/roadster)

指定動画では開発責任者が、10:13付近から前方の可動翼、12:53付近から後部の4基のファン、14:34付近から翼の駆動部、15:24付近から圧力容器とガス・スラスター、22:06付近からバルブの構成を説明しています。[Hagertyの開発者インタビュー](https://www.youtube.com/watch?v=22rvpUecLts&t=622s)

## 画面で対応させる部品

| 部品 | モデル・図で表す機能 |
| --- | --- |
| 電源 | バッテリーから電気を供給 |
| スイッチ | 教材上での起動・停止操作 |
| 制御基板 | モーター・翼・バルブの制御をまとめたブロック |
| 走行モーター | 車輪の駆動 |
| 吸引ファン | 床下の空気を吸い、車体を路面へ押し付ける働き |
| 翼の駆動部 | 可動翼の位置・角度を変える電動機構 |
| 電動バルブ | 電気によってガスの流れを開閉 |
| ガスタンク | 噴射に使う圧縮ガスの貯蔵 |
| ノズル | ガスを噴き出して推力を発生 |

電気の接続は「電源 → スイッチ → 制御基板 → 走行モーター／吸引ファン／翼の駆動部／電動バルブ → 電源」の簡略化した並列回路です。ガスの接続は「ガスタンク → 電動バルブ → ノズル」で、別の色と破線で示します。

吸引ファンのダウンフォースと、ガス噴射による浮上を別々の働きとして描いています。浮上時に見える白・水色の表現はガスの流れを示します。

## 教材としての簡略化

車体・内部部品・電気配線・配管の位置は、対応関係が見えるよう配置しています。制御回路は機能をまとめた模式図です。スイッチの位置、モーターやバルブの代表部品、浮上デモの高さ・時間も教材上の設計です。実車固有の寸法や圧力値、実際の飛行性能の数値計算は含めていません。

分解・表示切替・製品選択では電源を切り、アニメーションを初期位置へ戻します。電源を入れた際の浮上・着地デモは1回で終わり、再度の操作で繰り返せます。
